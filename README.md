# Hindi Varnamala Island Quest 🦚🥭

An interactive, bright, kid-friendly web game designed for 8-year-olds (especially learners from South India) to master and remember the **Hindi Varnamala** (13 Swar + 36 Vyanjan) forever.

## Key Features
- **🏠 South Indian Script Bridge**: Instant toggle between **Telugu (తెలుగు)**, **Tamil (தமிழ்)**, **Kannada (ಕನ್ನಡ)**, **Malayalam (മലയാളം)**, and **English Phonetics**.
- **🪄 Visual Shape Mnemonics**: Relates every Hindi letter shape to familiar everyday objects and the **"Number 3" Super-Shortcut**.
- **🐉 Dragon Breath Tester**: Teaches unaspirated vs. aspirated (*Mahaprana*) consonants with interactive puff-of-air tips and sound effects.
- **🎨 Rainbow Tracing Studio**: HTML5 Canvas letter and roofline (*Shirorekha*) tracing.
- **🕵️ Look-Alike Twin Detective**: Side-by-side memory tricks for commonly confused pairs (`ब vs व`, `घ vs ध`, `म vs भ`, `प vs ष`, `ट vs द`, `ड vs इ`, `क vs फ`).
- **🍲 Word Kitchen & Monster Arcade**: Build real Hindi words and earn collectible stickers.

## Deploying to Vercel
This project is pre-configured for zero-config static deployment on Vercel via `vercel.json`:
1. Push this repository to GitHub / GitLab / Bitbucket, or run `npx vercel` in this directory.
2. Import the repository in [Vercel](https://vercel.com/new) (Framework Preset: **Other**).
3. Click **Deploy**.
